================================================================================
PANDUAN PENGGUNAAN PAKET WEBSITE SOAL TKA SMK 2026
================================================================================

Paket ZIP ini berisi file lengkap untuk menjalankan website tes/tryout interaktif
secara lokal maupun diunggah ke hosting web:

1. index.html
   - Aplikasi Web Interaktif (Single File Website).
   - Sudah termasuk 50 Soal HOTS, Pilihan Ganda A-E, Timer Waktu, Otomatisasi Nilai/Skor,
     dan Pembahasan Detail Lengkap.
   - Cara Menggunakan: Cukup klik ganda (double-click) file `index.html` ini untuk
     langsung membukanya di Google Chrome, Mozilla Firefox, atau Edge tanpa butuh internet.

2. soal_tka_2026.json
   - Data struktur 50 soal dalam format JSON standar.
   - Sangat berguna jika Anda ingin mengintegrasikannya ke framework modern seperti
     React, Vue, Next.js, Laravel, Node.js, atau aplikasi Android/iOS.

3. Soal_TKA_SMK_Kewirausahaan_Ekonomi_2026.txt
   - Naskah soal mentah format teks polos.

4. Soal_TKA_SMK_Kewirausahaan_Ekonomi_2026.md
   - Naskah soal terstruktur format Markdown.
